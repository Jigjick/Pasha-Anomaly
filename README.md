# ✨ Pasha Anomaly

**Pasha Anomaly** — это веб-инструмент на базе SvelteKit для отслеживания **реального (истинного) процента исследования** локаций в *Genshin Impact* на основе данных из HoYoLAB Battle Chronicle.

В отличие от стандартного счётчика в игре, который округляет прогресс до 100% задолго до сбора всех сундуков, этот трекер показывает фактический потолок зачистки каждого региона и позволяет учитывать пропущенные временные события или исчезнувшие ящики с морой.

## 🚀 Основные особенности

* **Истинный процент зачистки:** точные максимальные значения исследования для всех регионов Тейвата (от Мондштадта до Натлана и Нод-Края).
* **Учёт пропущенных ящиков (0–4):** гибкий переключатель для деревянных ящиков с морой в Пруду Суйгэцу (остров Ватацуми), позволяющий скорректировать личный максимум.
* **Учёт старых ивентов:** перерасчёт прогресса для аккаунтов, участвовавших в событиях версий 1.3, 1.6, 2.0 и 2.2.
* **Современный дизайн:** обновлённый интерфейс с фиолетово-лавандовыми градиентами, тёмной темой и скруглёнными элементами.
* **Полная локализация:** адаптированный русский интерфейс и удобный скрипт-закладка для быстрого импорта статистики из HoYoLAB в один клик.

## 🛠️ Технологии

* **Фреймворк:** SvelteKit (Svelte 5) + TypeScript
* **Сборщик:** Vite
* **Локализация:** `svelte-i18n`
* **Хостинг:** GitHub Pages (Static Adapter)

## 📦 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```
